# 湖边鸭群

`src/ducks.js` 中的一只鸭妈妈和三只幼鸭为本项目原创程序化模型，由 Three.js 球体几何构建，没有引入第三方动物素材、贴图或声音。

模型构成、配色、步行动画与固定过路路径均在项目源码中，可随本项目商业使用。Three.js 继续遵守其依赖包附带的 MIT 许可。场景既有植被许可见 `assets/nature/README.md`。
