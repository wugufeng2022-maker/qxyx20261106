# 慢慢 · 乡野骑行

用 Three.js r187 制作的浏览器骑行游戏。沿 10 公里乡间小路骑行，经过村庄、果园、溪岸、森林和清湖。可以停下来等鸭群过路，也可以邀请小兔或小猫同行。

## 本地运行

需要 Node.js 20.19+（20.x）或 22.12+。

```sh
npm ci
npm run dev
```

打开终端打印的地址。用 `npm test` 跑测试，用 `npm run build` 生成可静态部署的 `dist/`。

## 骑行

- 点击「出发，去吹吹风」开始自动骑行。
- 轻点 W / ↑ 或「加速」切换持续加速。按住 S / ↓ 刹车。用 A / ←、D / → 或鼠标转向。
- 手机使用画面下方的触控按钮，支持时也可启用倾斜转向。
- 用「换个视角」切换镜头，用空格或「暂停骑行」歇一会儿。
- 开发模式的「场景跳转 DEV」可直接前往指定路段。绘画湖畔可用 `?previewAt=1123&previewPainting=1` 预览。

打开本地游戏时，可用 `?ride=creek`、`?ride=forest` 或 `?ride=lake` 分别从 5.28、5.98 或 6.73 公里出发。森林段从 6.00 公里延伸到 6.79 公里，沿途经过松林、林间空地和金叶树林。

麦野约 4.32 公里处，主路左边分出一条「画家村 / 写生小径」。路牌在岔口，箭头指向支线，并写着前方会汇回主路。继续骑主路就还在麦野里。要进支线，在两条路还连着的时候靠左：电脑按住 A 或 ←，手机按画面左下角的左转。支线是灰色柏油、暖黄昏和疏密不一的花木，没有彩石隔离墙。骑到尽头会自己回到主路。不进支线不会弹窗，也不会被送进画里。开发模式可以用「麦野画家 · 画前」看岔口；「星夜彩石村 · 画中」会直接站在支线上，只供查看，不写入旅途记录。记录和回退见 [星夜彩石村](docs/STARRY-VILLAGE.md)。

## 修改游戏

- `src/main.js` 管理骑行循环、镜头和界面。
- `src/route.js` 与 `src/scenery.js` 定义路线、地形和环境。路线规划见 [10 公里路线设计](docs/NATURAL-WORLD-ROUTE-PLAN.md)。
- `src/rider.js` 定义骑手和骑行动作。
- `assets/bicycle/` 和 `assets/rider/` 包含可编辑的 Blender 工程以及游戏使用的模型数据。对应目录的 README 记录导出方式，`assets/` 中还保留了素材的来源和许可。

协作时可从 `meadow-ride-r187` 新建分支，运行测试和构建后再提交 PR。
