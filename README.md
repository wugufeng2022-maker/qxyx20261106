# Cozy Creek · 小溪

A single-file Three.js creek demo. Three.js 0.187.0 is loaded from a CDN.

单文件 Three.js 小溪演示，通过 CDN 加载 Three.js 0.187.0。

## Run · 运行

Open `index.html` in a browser, or serve this folder with any static file server.

用浏览器打开 `index.html`，或用任意静态服务器托管本目录。

Drag to rotate and scroll to zoom. On a phone, drag with one finger and pinch to zoom.

拖动旋转，滚轮缩放。手机上单指拖动旋转，双指捏合缩放。
