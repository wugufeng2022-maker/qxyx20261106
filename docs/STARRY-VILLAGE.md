# 星夜彩石村

2026-11-07。在 `meadow-ride-r187`（`e9f100b`，延长小溪、清湖与 6.00–6.79 公里森林）上增加的第二种绘画主题。不替换湖畔印象派，不把普通世界改成夜晚，也不新开选关。

本分支没有 `AGENTS.md` 和 `docs/DEVELOPMENT-ROADMAP.md`。协作方式沿用 `docs/NATURAL-WORLD-STEPS.md`：保留恢复基线、补回归、看实际画面，并单独审查阻断与必须修复项。

## 玩家怎么遇到

金色麦野里，大约 4.32 公里，路边有一位画家和画架。画布是本项目自己画的竖幅习作。骑到画架前可以选择：

- 「走进这幅画」：从当前脚下开始，奶白色路面先接上，远处再转成淡金、粉桃和灰紫的暖黄昏，然后彩石墙、暖色房子和细干无叶树渐现。
- 「先往前骑」：不进入，这次经过不再询问。

画中的路就是原来的乡路，没有传送，镜头和转向也不换。悠闲巡航大约一分钟经过三段平缓弯，然后色彩和夜空一起退开，画家在前面的写生点收笔点头。可以中途「从画里出来」。没有奖励弹窗、没有障碍、没有雪地打滑。伙伴、手和声音偏好、原有操控都还在。旅途小记只多一行「麦野 · 星夜彩石村」，不会打开夜间主题。

本地入口：

```sh
npm run dev
```

打开 `http://127.0.0.1:5173/?ride=starry`，点「出发，去麦野看画」。开发菜单里「麦野画家 · 画前」是同一次相遇；「星夜彩石村 · 画中」只预览画中景色，刷新后不写入记录，也不会把麦野预览永久变成夜景。

## 素材

全部是程序生成，没有导入参考图，也没有调用收费生成模型。参考描述原来是深蓝夜空和黄月；玩家看过试玩后，远景改为柔和暖黄昏，地面改成能和麦野接上的米白小路。原图作者和商用许可未知，所以不复制像素。

- 天空：球面顶点色，地平线淡金，中段粉桃，上方灰紫。没有方板，也没有近黑填充。月亮放在天球高处，颜色是淡奶油，不作为聚光灯。
- 路面：128×128 低对比水彩块，开 mipmap，中线只有少量嵌进顶点色的彩砖，没有悬浮砖条。路肩用同一类大色块过渡到暖草地，并加很低的草丛。
- 卵石、房屋、树枝：网格和顶点色，不用整屏贴图。房屋边线是暖褐，不是纯黑。
- 画架上的小习作：160×220 画布，同一套形状。
- 画家使用游戏已有的自行车和骑手，衣服颜色单独克隆，不改玩家自己的模型和材质。

## 局限

- 画中路在 4490–4810 米加了一条接回原路的横向缓弯，振幅 7.6 米、一个半波形，两端偏移和斜率都是 0。车和镜头跟着这条弯走，离开画中后回到原来的中线。路面半宽 2.15 米，和乡路一样，不再铺成宽平板。
- 低墙是错落层数的彩石砌块，不是一串圆球。房子按组放在弯道两侧，带白顶、门和窗。
- 弯道路面按所在位置的实际地面抬高，避免沉进麦田后骑手看起来站在黄地上。4490–4810 米每 10 米抽样道路网格，确认骑行宽度在路面内、墙不跨路、路面不低于地面。
- 远景是暖黄昏，不是夜空。天球从淡金接到粉桃和灰紫，雾是同一暖色，远处还能看见房子和路。月亮是淡奶油色，灯光从低处照过来，不再把房子背面打成纯黑。离开画中后背景回到白天的 `#dce7d0`。
- 路面仍是半宽 2.15 米的奶白路，中线只有嵌在路面里的少量彩点，没有悬浮砖条。路肩跟着弯道铺开，近处略有起伏和矮草，并盖住脚下那一块麦田黄地。画外的麦野颜色不改。
- 画中大约一分钟按悠闲巡航（约 5 米/秒）计算。轻快或追风会更短，下车推行会更长。
- 中途离开会直接把色彩淡出，不再走到写生点告别。
- 同一轮经过里拒绝或完成后不会再问。重新打开页面可以再遇到。
- 星空和黄月挂在跟随骑手的天球上，是环境而不是贴在屏幕上的图。
- 本环境的软件渲染大约一秒一帧，不能代表玩家机器上的帧率。
